
# 🧩 HỆ THỐNG QUẢN LÝ SINH VIÊN - Student Management System

## Giới thiệu  
Hệ thống Quản lý Sinh viên là một ứng dụng web được phát triển trên **Laravel Framework (PHP)** kết hợp với **MySQL** để lưu trữ và quản lý dữ liệu.  
Hệ thống hỗ trợ quản lý sinh viên, học viên, chương trình học và lớp tín chỉ trong môi trường học tập hiện đại, giúp người quản trị thực hiện các thao tác **nhanh chóng, chính xác và thuận tiện** so với phương pháp truyền thống.  

---

## Chức năng chính  

### 🔹 Sinh viên  
- Đăng nhập / Đăng xuất  
- Tra cứu chương trình học  
- Tra cứu bảng điểm cá nhân  
- Tra cứu lớp học tín chỉ  

### 🔹 Quản trị viên  
- Đăng nhập / Đăng xuất  
- Quản lý danh sách sinh viên  (Thêm/ Sửa/ Xóa/ Xem)
- Quản lý danh sách học viên  (Thêm/ Sửa/ Xóa/ Xem)
- Quản lý chương trình học  (Thêm/ Sửa/ Xóa/ Xem)
- Quản lý điểm  (Thêm/ Sửa/ Xóa/ Xem)
- Quản lý lớp tín chỉ  (Thêm/ Sửa/ Xóa/ Xem)

##  Hướng dẫn cài đặt dự án  

- Bước 1: Clone repository  
```bash
git clone https://github.com/ngoc0110/My_web.git
cd My_web
```

- Bước 2: Cài đặt thư viện PHP
```bash
composer install
```

- Bước 3: Cài đặt thư viện Frontend
```bash
npm install
npm run dev
```

- Bước 4: Chạy server
```bash
php artisan serve
```
