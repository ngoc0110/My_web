# Student Management System

## Giới thiệu
Dự án **Quản lý sinh viên** được xây dựng bằng **Laravel** nhằm quản lý thông tin sinh viên, giảng viên và môn học.  
Hệ thống hỗ trợ đăng nhập bằng **tên tài khoản (username)**, phân quyền theo vai trò và hiển thị giao diện thông qua **Blade Template**.

---

## Mục tiêu
- Tìm hiểu và áp dụng **Authentication** trong Laravel (đăng nhập / đăng xuất).
- Sử dụng **Middleware** để kiểm soát truy cập.
- Thiết kế giao diện động bằng **Blade Template**.
- Quản lý dữ liệu sinh viên, giáo viên, môn học trong cơ sở dữ liệu MySQL.

---

## Kiến trúc dự án
- **Framework:** Laravel 11  
- **Ngôn ngữ:** PHP 8.2  
- **Cơ sở dữ liệu:** MySQL  
- **Frontend:** HTML, CSS, Bootstrap, Material Dashboard  
- **Template engine:** Blade
